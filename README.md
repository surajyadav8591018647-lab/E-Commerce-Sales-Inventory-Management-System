E-Commerce Sales & Inventory Management System

Project Overview

This project analyzes e-commerce sales, customer orders, product performance, and inventory using SQL.

Tools Used

- MySQL
- MySQL Workbench

SQL Concepts

- SELECT, WHERE, ORDER BY
- Aggregate Functions (SUM, COUNT, AVG)
- JOINs
- GROUP BY and HAVING
- CASE Statements
- Subqueries

Business Questions

- Which products generate the highest revenue?
- Who are the top customers by order count?
- Which products have low inventory?
- What is the total revenue from successful payments?
- Which products are performing best?
